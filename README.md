# Wreckbound

Single-player space salvage shooter for **50.033 Game Development and Design**. Explore derelict stations, collect supplies and return to your shuttle before time runs out.

## Development

Open this repository in **Unity 6000.6.0f1**. Our [Game Design Document](https://docs.google.com/document/d/1weYnM30BoRGHu19m4mcrVLmyRmSAgmvRpOZj1PDKtE0/edit?tab=t.0) tracks the evolving design, architecture and team responsibilities.

## Project Instructions

- [Course website and project instructions](https://natalieagus.github.io/50033/about/admin/game-project/)
- [Grading spreadsheet](https://docs.google.com/spreadsheets/d/1Wkg6RepJ_qm4G0Imsajb_64UxfumRszM5iDtrIPaoUo/edit)
- [GDD template](https://docs.google.com/document/d/1lHJUf-IeGTzXYDUF9l9ziWfCnvAeJA3BWRWDzdTA6vY/edit)

Final submission: playable executable, public source repository, final GDD PDF, downloadable gameplay recording (no YouTube), presentation and peer review. Aim for approximately 15 minutes of meaningful gameplay, with documented playtesting and iteration.

The calendar and project page list different final deadlines; check eDimension for confirmation and submission links.

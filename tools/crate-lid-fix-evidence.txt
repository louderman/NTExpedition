Cause
  The crate's world SpriteRenderer referenced only the SS14 `base` state (generic.rsi layer 0,
  Crates/Steel/base.png — the lidless body). Upstream draws a crate as base + a `Door` lid layer
  that is `closed` when shut and `open` when open
  (frontier-station-14/.../Crates/base_structurecrates.yml, EntityStorageVisuals
  stateDoorClosed: closed / stateDoorOpen: open). The port never carried the Door layer and
  StorageCrate.cs never touched any sprite, so the crate was lidless in every state.
